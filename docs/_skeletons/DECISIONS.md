# Décisions

Journal des décisions structurantes de **ce** projet. Format : contexte → décision →
conséquences. Une décision annulée n'est pas effacée : elle est marquée « remplacée par
D-0xx ».

Les décisions héritées du squelette (choix de next-forge, correctifs de dérive amont,
outillage qualité) sont dans l'historique Git du squelette, pas ici.

**Date** : AAAA-MM-JJ
**Contexte** : quel problème réel se posait, avec les faits observés.
**Décision** : ce qui a été choisi, et ce qui a été écarté.
**Conséquences** : ce que cela impose, interdit ou rend possible ensuite ; ce qui reste
non vérifié.
